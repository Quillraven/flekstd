# Fleks TD

## 🎮 General

Tower defense sandbox built as part of a LibGDX Kotlin tutorial series on [my YouTube channel](https://www.youtube.com/@Quillraven).

The game features three towers (Warrior, Archer, Monk) and two enemy types (Pawn, Lancer). Towers fire projectiles and can apply Slow and Splash effects. The entire project follows a strict Entity Component System (ECS) architecture.

## 🛠️ Technology

- **Language:** Kotlin
- **Framework:** [LibGDX](https://libgdx.com/) with [KTX](https://github.com/libktx/ktx) extensions
- **ECS:** [Fleks](https://github.com/Quillraven/Fleks)
- **Build:** Gradle (JVM 17)
- **Platforms:** Desktop (LWJGL3), Web (TeaVM)

## 🕹️ Controls

| Area | Action |
|---|---|
| Bottom-left panel | Build towers one at a time (Warrior, Archer, Monk) |
| Bottom-center button | Spawn the configured wave |
| Bottom-right panel | Configure the wave — set how many Pawns and Lancers should spawn |
